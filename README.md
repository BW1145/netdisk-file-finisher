# 网盘文件收尾

Windows 10 / 11 x64 便携工具。拖入一个文件，直接提取藏在视频或图片中的压缩包，也可以恢复百度网盘收尾报错的下载文件。

## 使用

1. 从 GitHub Releases 下载并运行 `NetdiskFinisher.exe`。
2. 将文件拖进窗口，或点「选择文件」。成功后，程序在资源管理器中定位成品。单文件保留解包后的文件名，多文件放进原件旁的同名文件夹。
3. 要自动处理，选择一个目录并开启「自动解包」。新增和刚下完的文件会排队处理，包含子目录。第一次开启只登记已有文件。关闭软件期间新到的文件，会在重开后补处理。

支持 ZIP、RAR 和 7z，按内容识别格式。视频或图片末尾附带的 ZIP 也支持。每一层只解出一个压缩包时，程序继续解下一层。需要密码时，默认先试文件所在目录的上一级目录名，再试文件所在目录名。也可以输入密码重试。

设置中可选择在成功解包后把原件移到回收站，默认保留。中间包和临时目录由程序管理。监听状态及处理记录保存在 Windows 应用数据目录。

## 下载恢复

普通下载临时文件依照网盘记录校验。视频没有可用的匹配校验值时，需要 FFmpeg 检查音视频。系统 PATH 里的 FFmpeg 或放在程序旁的 `ffmpeg.exe` 都可以使用。

## 构建

使用 Windows x64 和 Python 3.12。构建脚本下载并校验固定版本的官方 7-Zip，生成带解包组件的单文件 EXE。

```powershell
./build.ps1
./.venv-build/Scripts/python.exe -X utf8 -m unittest -v
```

发布包记录版本、源码提交和 SHA-256。Windows Actions 从版本标签构建，测完后生成待验收的发布草稿。

NetdiskFinisher 源码使用 MIT 许可。程序调用 7-Zip 26.05 的 `7z.exe` 与 `7z.dll`，相关组件采用上游 GNU LGPL 及适用的 unRAR 限制。许可证随 ZIP 发布，源码见 [7-Zip 官方发布](https://github.com/ip7z/7zip/releases/tag/26.05) 和 [7-Zip 官网](https://www.7-zip.org/)。FFmpeg 是独立依赖，许可随所选构建提供。
