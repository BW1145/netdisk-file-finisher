# 网盘文件收尾

Windows 图形工具，用于从百度网盘收尾报错的下载临时文件中导出可使用的副本。支持批量扫描、单文件处理、内容识别、视频检查、压缩包检查和重复导出识别。

## 使用

1. 从 Releases 下载 Windows 压缩包，解压后双击 `NetdiskFinisher.exe`。
2. 首次选择网盘实际使用的下载目录。保存位置默认设为该目录下的 `收尾导出`，也可以自行选择其他磁盘。
3. 点击 **扫描并自动处理**，或 **选择一个文件处理**。
4. 查看每行结果，点击 **打开保存文件夹**。正常导出的文件放在 `导出文件` 中。

遇到问题时打开工具即可。设置会保存在 `%LOCALAPPDATA%/NetdiskFileFinisher/设置.json`，下次运行会记住目录。处理记录保存在所选保存位置的 `处理记录.json`。

Release 提供独立 EXE、版本 ZIP 和 `SHA256SUMS.txt`。ZIP 内包含程序、使用说明、许可证和 `BUILD_INFO.json`，其中记录版本、源码提交和 EXE 的 SHA-256。

## 如何判断与导出

| 文件情况 | 处理方式 |
| --- | --- |
| 普通文件有可用网盘校验值 | 完整 MD5 一致后导出 |
| MP4 / MOV / MKV / WebM，缺少匹配校验值 | 使用 FFmpeg 从头到尾解码音视频后导出 |
| ZIP | 有可用网盘 MD5 时先核对完整源文件，再检查文件位置及未加密条目的 CRC |
| 视频或其他前缀后附带 ZIP | 根据 ZIP 自身偏移去掉前缀，导出独立 `.zip` |
| 加密 ZIP，包括 WinZip AES | 导出保留加密的 ZIP；显示“目录可读；加密内容未验证” |
| RAR / 7Z / GZIP / BZIP2 / XZ / TAR | 按开头特征识别，优先匹配校验值，否则调用系统 tar 读取检查 |
| 缺少依据、检查失败或文件还在变化 | 显示原因；可主动使用“导出待核查副本”自行检查 |

文件类型按内容识别。ZIP 检查优先于视频检查，因而能处理改成视频后缀、或者带视频封面的压缩包。带前缀 ZIP 的网盘 MD5 对应包含前缀的完整源文件，导出时再去掉前缀。正在下载或记录显示未完成的 ZIP 与其他文件一样等待；收尾报错任务可继续检查。加密 ZIP 的导出保持原有加密，解压时使用原密码。

导出时复制数据，核对复制前后的源数据和导出副本 SHA-256。工具保留下载源文件及网盘任务，并以只读方式查询本机任务数据库。文件名冲突时另存编号副本；重复处理核对当前源数据与已有副本的 SHA-256 后复用结果。损坏的处理记录条目会被跳过；副本已导出但记录保存失败时，结果仍显示“已导出”，并提示下次可能再次导出。

处理记录先写入同目录临时文件，完成缓冲区刷新和磁盘同步后再原子替换正式记录；替换前失败时保留旧记录，并在异常退出路径清理临时文件。

**导出待核查副本** 会把副本放入单独的 `待核查副本` 文件夹，并明确标注内容完整性未验证。ZIP 前缀识别同样适用于该操作。

## 环境

- Windows 10 / 11，64 位。已打包程序包含 Python 运行时和图形界面。
- 无匹配校验值的视频检查需要 FFmpeg。程序依次查找同目录的 `ffmpeg.exe`、系统 PATH、WinGet 安装链接。可从 [FFmpeg 官方下载页](https://ffmpeg.org/download.html)所列的 Windows 构建获取，把 `ffmpeg.exe` 放到本工具旁边。
- 其他压缩格式使用 Windows 自带的 `tar.exe`；格式或加密方式不受其支持时，界面会报告检查结果。
- 保存磁盘需要能容纳一份导出副本。较大视频的完整检查需要时间，界面持续显示当前步骤，可点击停止。

音视频解码检查针对音频和视频流；加密包的目录检查针对结构。界面会分别显示采用的检查依据。

## 开发与构建

使用 Python 3.12，运行时仅依赖标准库。

```powershell
python -X utf8 app.py
python -X utf8 -m unittest -v test_finisher
./build.ps1
```

`build.ps1` 在项目内创建独立构建环境，安装 `requirements-build.txt` 中固定的 PyInstaller，输出 `dist/NetdiskFinisher.exe`。有关打包选项见 [PyInstaller 官方文档](https://pyinstaller.org/en/stable/usage.html)。

测试使用临时生成的文件，覆盖带前缀 ZIP、加密包选项、损坏 ZIP、完整视频和截断视频、未完成任务、复制期间数据变化、取消、只读数据库、Windows 文件共享和重复处理。视频测试需要 FFmpeg，缺少时明确跳过。

处理记录测试还覆盖 UTF-8 原子写入、部分写入失败、刷新失败、同步失败、替换失败及可处理的中断，检查旧记录保留、临时文件清理和导出成功提示。

GitHub Actions 在 Windows 上运行测试、构建 EXE、执行打包后的 GUI 自检，并生成 ZIP 和 SHA-256 校验文件。推送 `v*` 版本标签时，后续发布任务使用该次构建的产物创建 GitHub Release。版本标签应指向已审查并通过测试的提交，例如：

```powershell
git tag -a v1.0.1 -m "网盘文件收尾 v1.0.1：处理记录原子保存与 Windows 自动发布"
git push origin v1.0.1
```

## 数据与许可

程序在本机运行。运行时设置和处理记录用于记住目录与避免重复导出；记录包含本机路径和文件校验信息。源码仓库和发布包采用通用示例。

项目源码采用 MIT 许可证。FFmpeg 是独立依赖，其许可随所选构建提供。
